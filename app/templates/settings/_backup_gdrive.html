Google Drive Configuration

How to set this up
  1. In Google Cloud Console, enable the Google Drive API for a project.
  2. Create a service account in that project and download a JSON key for it.
  3. In Google Drive, open a Shared Drive (Google Workspace required) and add the service account's email as a member with the Content manager role.
  4. Create or pick a folder in that Shared Drive and paste its link or ID below.

Service accounts have no storage of their own, so a folder in a personal My Drive will not work.
